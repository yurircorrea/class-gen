Requisições AJAX com fetch

Como as páginas conversam com o servidor sem recarregar, e como escrever isso em JavaScript.

01

Recarregar a página inteira ou só uma parte

No modelo clássico, cada clique pede uma página HTML nova e a tela é desenhada de novo. Com AJAX, o JavaScript pede só os dados e troca só o pedaço que mudou.

modelo clássico · a página toda volta
loja.exemplo/produto/mochila
requisições: 0
com AJAX · só os dados viajam
loja.exemplo/produto/mochila
requisições: 0

Calcule o frete nas duas janelas. À esquerda a tela some e volta, o relógio muda e a observação digitada se perde: a página inteira foi trocada. À direita só a linha do frete muda, e chegam bem menos bytes.

o formulário pede uma página nova
o JavaScript pede só os dados

A página toda volta

Clique, o navegador pede um HTML novo, a tela pisca e tudo é desenhado de novo, inclusive o que não mudou: cabeçalho, menu, rodapé.

Só os dados viajam

O JavaScript pede um JSON pequeno e altera só o elemento que mudou. O que a pessoa digitou e a posição da rolagem continuam lá.

Armadilha: o endereço não muda

Com AJAX a barra de endereço fica igual. Recarregar (F5) ou voltar não “lembram” o que foi buscado. Quando isso importa, o estado vai para a URL ou para o localStorage.

02

O que significa AJAX

Asynchronous JavaScript And XML. Não é uma linguagem, é uma técnica: junta o que você já conhece, JavaScript, requisições HTTP, JSON e o DOM.

Asynchronous

A página continua funcionando enquanto espera a resposta. Ninguém fica travado olhando para uma tela parada.

JavaScript

É quem faz o pedido ao servidor e quem atualiza a tela quando a resposta chega.

And XML

O formato de dados do começo, em 2005. Hoje quase sempre é JSON, mas o nome ficou.

consoleo 2 aparece antes do 3
como era · XMLHttpRequest
como é hoje · fetch

Técnica, não linguagem

Não há nada para instalar. AJAX é o nome de um jeito de usar o navegador: evento, requisição, resposta e DOM.

XML virou JSON

JSON é texto que o JavaScript transforma em objeto com uma chamada. Por isso tomou o lugar do XML nas APIs.

fetch é nativo

Existe em todos os navegadores atuais e também no Node.js a partir da versão 18. O XMLHttpRequest ainda funciona, mas código novo usa fetch.

03

O caminho de uma requisição

Quatro passos, sempre os mesmos: um evento, a requisição, a resposta e a atualização do DOM. Digite um CEP e saia do campo, ou use um dos botões.

1

Evento

O usuário digita um CEP e sai do campo.

2

Requisição

O JavaScript chama fetch e pede os dados ao servidor.

3

Resposta

O servidor devolve os dados em JSON.

4

Atualização

O JavaScript altera só os campos no DOM.

      06
      
    A sintaxe do fetch
    
    
    
    
    fetch(url, opcoes) dispara a requisição e devolve na hora uma Promise: a promessa de que a resposta vai chegar depois.
    

    
    
      
      
    
        
    consolea Promise vem antes da resposta
    
        
    
          
    
          
    
        
    
      
    
    
    

    
    
      
    url · obrigatória
    O endereço do recurso. Pode ser completo (https://...) ou relativo ao site (/api/frete).
    
      
    opcoes · opcional
    Um objeto com method, headers, body e signal. Sem ele, o pedido é um GET.
    
      
    retorno · uma Promise
    Que vira um objeto Response quando o servidor responde. Por isso o primeiro console.log mostra a Promise, não os dados.
    
    
    
  
    

  
  
    
    
    
      07
      
    Promises e seus três estados
    
    
    
    
    Pense na senha de uma lanchonete: você recebe a senha na hora (a Promise) e o lanche (os dados) chega depois. Ou não chega, se a cozinha fechar.
    

    
    
      
    ⋯
    pending · pendente
    A requisição foi enviada e ainda não voltou. Você está com a senha na mão.
    
      
    ✓
    fulfilled · resolvida
    A resposta chegou. Quem trata é o .then().
    
      
    ✕
    rejected · rejeitada
    Algo falhou, como a falta de Internet. Quem trata é o .catch().
    
    
    

    
    
      
      
    
        
    consoleescolha a situação
    
        
    
          
    
            
            
          
    
          
    
          
    
        
    
      
    
    
    

    
    
      
    Uma Promise muda de estado uma vez
    Sai de pending para fulfilled ou para rejected e fica ali. Não volta a ficar pendente.
    
      
    .then() e .catch() devolvem Promises
    Por isso dá para encadear: cada .then() recebe o que o anterior devolveu.
    
      
    Armadilha: “Failed to fetch” não diz o porquê
    Sem Internet, endereço que não existe ou servidor que bloqueia o seu site (CORS): todos chegam como o mesmo TypeError. A aba Rede do F12 mostra o motivo.
    
    
    
  
    

  
  
    
    
    
      08
      
    Lendo a resposta com .then()
    
    
    
    
    A primeira Promise entrega um objeto Response. resposta.json() lê o corpo e devolve outra Promise, com os dados já como objeto.

    text()o corpo cru, como chegou
    
        
        
    
      
    
    
    

    
    
      
    json() também espera
    O corpo pode ainda estar chegando quando o Response aparece. Por isso json() devolve uma Promise e precisa de outro .then().
    
      
    Response tem mais
    status, ok (verdadeiro de 200 a 299), headers.get(), e os leitores json(), text() e blob().
    
      
    Armadilha: chaves sem return
    r => r.json() devolve o valor. r => { r.json(); } não devolve nada, e o próximo .then() recebe undefined.

      10
      
    Quando dá errado
    
    
    
    
    Sem conexão, pedido recusado, “não achei”: cada falha chega de um jeito. O fetch só rejeita quando não existe uma resposta que o navegador deixe o seu código ler.

    Quando não há resposta nenhuma, a Promise é rejeitada e o catch recebe um TypeError. Avise quem usa e ofereça tentar de novo.

      13
      
    Enquanto a resposta não chega
    
    
    
    
    Rede lenta é normal, principalmente no celular. A interface precisa avisar que está buscando, impedir o clique duplo e desistir depois de um tempo.

    Avise que está buscando
    Sem aviso, meio segundo parece que nada aconteceu e a pessoa clica de novo. Um texto “buscando…” ou um indicador resolve.
    
      
    finally devolve o botão
    O bloco finally roda com sucesso ou com erro. É o lugar de reabilitar o botão e esconder o “carregando”.
    
      
    AbortSignal.timeout()
    O fetch não tem tempo limite: sem signal, ele espera o quanto o navegador deixar. AbortSignal.timeout(ms) cancela a requisição e rejeita com TimeoutError. Funciona em todos os navegadores atuais.

      14
      
    Formatar na mão sempre quebra
    
    
    
    
    Concatenar texto resolve um caso e falha em todos os outros: separador de milhar, posição do símbolo, ordem de dia e mês, fuso horário, plural, acento na ordenação. A API Intl já vem no navegador e cuida disso.
    

    
    
      
    
        na mão
        
        
    
      
    
      
    
        com Intl
        
        
    
      
    
    
    

    
    
      
    Nativa, sem instalar nada
    Intl existe em todos os navegadores e no Node.js. Você informa o locale e o que quer exibir; ela aplica as convenções daquele idioma e região.
    
      
    Os dados não mudam
    O preço continua sendo o número 1234.5 e a data continua sendo um Date. Só o texto exibido muda de idioma para idioma.
    
      
    Armadilha: getMonth começa em zero
    Novembro é 10. Somar 1 na mão corrige este caso, mas não resolve zero à esquerda, ordem dia/mês nem nome do mês. A seção 21 volta a isso.
    
    
    
  
    

  
  
    
    
    
      15
      
    Locale: idioma mais região
    
    
    
    
    Um locale é uma etiqueta de idioma: a primeira parte é o idioma, a segunda é a região. É ela que decide vírgula ou ponto, a ordem da data e o nome do mês.
    

    
    
      
    
        
    controles
    
        
    
          
          
        
    
        
    
          
          
        
    
        
    A data é sempre 2026-11-04T14:30:00Z, exibida no fuso de São Paulo. A linha destacada é o locale deste navegador.
    
      
    
      
    
        
    
        
    
      
    
    
    

    
    
      
      
    
        
    consoleo navegador desta sala
    
        
    
      
    
    
    

    
    
      
    pt-BR não é pt-PT
    Mesmo idioma, regiões diferentes: compare as duas linhas da tabela no separador de milhar e no nome da moeda.
    
      
    undefined usa o navegador
    Sem locale, vale navigator.language. Bom para mostrar a data no idioma de quem abriu; ruim quando a tela precisa sair igual para todos.
    
      
    Armadilha: idioma não é moeda
    O locale define como escrever; a moeda vai à parte. Um preço em dólar exibido para um brasileiro continua em USD: US$ 1.234,56.
    
    
    
  
    

  
  
    
    
    
      16
      
    A família Intl
    
    
    
    
    Seis formatadores com o mesmo jeito de usar: new Intl.Algo(locale, opcoes) e depois format (ou compare, ou select).
    

    
    
      
    
        
    NumberFormatnúmeros, moedas, percentuais, unidades
    
        
        
    
      
    
      
    
        
    DateTimeFormatdatas e horas, com fuso
    
        
        
    
      
    
      
    
        
    RelativeTimeFormatontem, há 3 dias, em 2 meses
    
        
        
    
      
    
      
    
        
    Collatorcomparar e ordenar texto com acento
    
        
        
    
      
    
      
    
        
    ListFormatAna, Léo e Zoe, com o conectivo certo
    
        
        
    
      
    
      
    
        
    PluralRulesdecide entre singular e plural por idioma
    
        
        
    
      
    
    
    

    
    
      
      
    
        
    consoleas mesmas opções, sem new
    
        
    
      
    
    
    

    
    
      
    Um padrão para os seis
    Construtor com locale e opções, depois um método. Aprendeu um, aprendeu a família.
    
      
    O atalho: toLocaleString
    Aceita exatamente as mesmas opções. Prático para uma chamada isolada; para repetir em laço, crie o formatador uma vez (seção 25).
    
      
    Novo na família: DurationFormat
    Intl.DurationFormat escreve durações como “1 hora e 30 minutos”. Chegou aos três navegadores principais em 2025; confira o suporte antes de usar em produção.
    
    
    
  
    

  
  
    
    
    
      17
      
    Intl.NumberFormat: o básico
    
    
    
    
    Dois argumentos: o locale e um objeto de opções. O método format recebe o número e devolve o texto pronto.

    Quatro armadilhas de data
    
    
    
    
    Um Date guarda um instante, não um texto. A data que aparece depende do fuso usado para exibir, e é aí que mora o famoso bug do “um dia a menos”.
    

    
    
      
    
        
    o mês começa em zeroem new Date(2026, 10, 4), o 10 é novembro
    
        
        
    
      
    
      
    
        
    Date guarda um instantemilissegundos desde 1970, em UTC
    
        
        
    
      
    
      
    
        
    "2026-11-04" é lido como UTCmeia-noite em UTC ainda é dia 3 no Brasil
    
        
        
    
      
    
      
    
        
    guarde em ISO, exiba com Intlo texto ISO vai e volta sem perder nada
    
        
        
    
      
    
    
    

    
    
      
    Date não tem fuso
    É um número de milissegundos em UTC. O fuso só entra quando você exibe: timeZone no Intl, ou o do computador se você não disser nada.
    
      
    Vencimento? timeZone: "UTC"
    Para data de calendário sem hora (vencimento, aniversário), formate com timeZone: "UTC". O dia exibido é sempre o dia gravado, em qualquer máquina.
    
      
    Armadilha: um dia a menos
    new Date("2026-11-04") é meia-noite em UTC. Exibida no Brasil (UTC−3), vira 21h do dia 3. É o bug mais comum de datas em JavaScript.

    Tempo relativo: ontem, há 3 dias
    
    
    
    
    Intl.RelativeTimeFormat escreve “há 3 dias” e “em 2 meses”. Negativo é passado, positivo é futuro. A conta da diferença é sua.
    

    
    
      
      
    
        
    consolenumeric: "auto" usa palavras quando existem
    
        
    
      
    
    
    

    
    A conta é sua: escolher a unidade
    
    
    
      
      
    
        
    previewarraste: diferença em dias
    
        
    
          
          
    
          
    
        
    
      
    
    
    

    
    
      
    Negativo é passado
    -3 é “há 3 dias”; 2 é “em 2 dias”. A unidade vai em inglês, no singular ou no plural: "day" ou "days", "month", "year".
    
      
    numeric: "auto"
    Troca o número por uma palavra quando o idioma tem uma: ontem, hoje, amanhã. Com "always" (o padrão), sai “há 1 dia”.
    
      
    Armadilha: a API não subtrai datas
    RelativeTimeFormat só escreve. Você calcula a diferença, escolhe a unidade e arredonda. Na régua, compare “sempre em dias” com as outras linhas.

    Collator: ordenar com acento
    
    
    
    
    O sort sem argumento compara texto pelo código de cada caractere: letras acentuadas e minúsculas caem fora de ordem. O Collator compara pelas regras do idioma.
    

    
    
      
      
    
        
    consoleÁ vem depois de Z na tabela de caracteres
    
        
    
      
    
    
    

    
    
      
    
        
    numeric: true"item 2" antes de "item 10"
    
        
        
    
      
    
      
    
        
    sensitivity: "base""jose" encontra "José"
    
        
        
    
      
    
      
    
        
    maiúsculaso sort comum põe todas antes
    
        
        
    
      
    
    
    

    
    
      
    compare é a função de ordenação
    Devolve negativo, zero ou positivo, como o sort espera. Passe col.compare sem parênteses.
    
      
    localeCompare é o atalho
    a.localeCompare(b, "pt-BR") faz o mesmo. Para listas longas, o Collator criado uma vez é mais rápido.
    
      
    Armadilha: compare não busca trechos
    Ele compara textos inteiros. Para “começa com”, corte o nome do tamanho da busca antes de comparar, como no exemplo do meio.

    ListFormat e PluralRules
    
    
    
    
    Duas que ficaram de fora dos slides, mas aparecem em toda tela: juntar nomes com o conectivo certo e escolher entre singular e plural.
    

    
    
      
    
        
    ListFormat“e”, “and”, “ou”, conforme o idioma
    
        
        
    
      
    
      
    
        
    PluralRulesdevolve a categoria, você escolhe a palavra
    
        
        
    
      
    
      
    
        
    type: "ordinal"1st, 2nd, 3rd em inglês
    
        
        
    
      
    
    
    

    
    
      
    ListFormat
    type: "conjunction" (padrão, “e”), "disjunction" (“ou”) e "unit" (“3 kg, 20 g”). Com um item só, não sobra vírgula.
    
      
    PluralRules não traduz
    Ela devolve uma categoria (one, two, few, many, other). As palavras ficam num objeto seu, uma por categoria.
    
      
    Armadilha: o zero em português
    Pelas regras de pt-BR, 0 é one: sai “0 item”. Trate o zero à parte, com “nenhum item”, antes de consultar a regra.

    Um módulo de formatadores
    
    
    
    
    Os formatadores do projeto ficam num arquivo só, criados uma vez. As telas importam o que precisam e formatam na última linha antes de escrever na página.
    

    
    
      
      
    
    

    
    
      
      
    
        
    previewa tela do pedido com os dois arquivos acima
    
        
    
      
    
    
    

    const brl = new Intl.NumberFormat("pt-BR", { style: "currency", currency: "BRL" });
const dataCurta = new Intl.DateTimeFormat("pt-BR", { dateStyle: "short", timeZone: "America/Sao_Paulo" });
const colator = new Intl.Collator("pt-BR", { numeric: true });
const lista = new Intl.ListFormat("pt-BR");
const pedido = { total: 1234.5, criadoEm: "2026-11-04T14:30:00Z" };
const clientes = [{ nome: "Zoe" }, { nome: "Álvaro" }, { nome: "Ana" }];
clientes.sort((a, b) => colator.compare(a.nome, b.nome));
document.querySelector("#total").textContent = brl.format(pedido.total);
document.querySelector("#quando").textContent = dataCurta.format(new Date(pedido.criadoEm));
document.querySelector("#clientes").textContent = lista.format(clientes.map(c => c.nome));

    

    
    
      
    O dado continua cru
    pedido.total é número e pedido.criadoEm é uma string ISO. A formatação acontece na última linha antes de escrever na tela, e só ali.
    
      
    Um lugar só para mudar
    Trocar o fuso, as casas decimais ou o idioma do sistema inteiro é editar formatadores.js. Nenhuma tela muda.
    
      
    Armadilha: módulo por duplo clique
    <script type="module"> não carrega quando o arquivo é aberto por file://: o navegador bloqueia o import. Abra o projeto com um servidor local, como a extensão Live Server do VS Code.

    Toda mensagem de erro aparece em texto na tela, todo campo tem <label>, o botão ou campo não aceita busca dupla, e valor negativo não depende só da cor.
