Item 1

Role esta caixa e observe o menu ao lado marcando sozinho o item correspondente. O scrollspy do Bootstrap 5.3 usa a API Intersection Observer.

Cada título precisa de um id, e cada link do menu precisa apontar para esse id.

Item 1-1

Subitens também são marcados, desde que estejam aninhados no menu com a mesma estrutura de nav.

O menu não precisa ser vertical: funciona igualmente em uma navbar horizontal.

Item 2

O antigo atributo data-bs-offset foi descontinuado na versão 5.2 e substituído por data-bs-root-margin.

Outra novidade é data-bs-smooth-scroll="true", que faz a rolagem suave ao clicar em um link do menu.

Sem esse atributo o salto é instantâneo, como no HTML puro.

Item 3

O elemento que rola precisa de tabindex="0" para poder receber foco e ser navegável pelo teclado.

Item 3-1

Quando a caixa de rolagem é a própria página, aplique os atributos no <body>.

Isso é o mais comum em páginas de uma seção só (landing pages).

Item 3-2

Fim da lista. Role de volta para cima e acompanhe a marcação mudando no menu.
